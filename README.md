# Agentic AI-Powered Digital Twin for Manufacturing Operations

An experimental manufacturing digital twin combining discrete-event
simulation, machine learning, predictive maintenance and agentic AI.

## Architecture

Manufacturing System
→ Digital Twin
→ Time-Series Data
→ Machine Learning
→ Failure Prediction
→ AI Decision Agent
→ Autonomous Action
→ Preventive Maintenance

## Features

- Manufacturing simulation using SimPy
- Machine digital twins
- Time-series monitoring
- Event logging
- Anomaly detection using Isolation Forest
- Predictive maintenance
- Autonomous maintenance decision agent
- Baseline vs agent-controlled experiments

## Experimental Results

Across 30 paired simulation runs:

- Reactive downtime reduced by 90%
- Throughput increased by 3.69%
- Average cycle time reduced by 1.37%
- Reactive failure runs reduced from 30/30 to 3/30

## Technologies

- Python
- SimPy
- Pandas
- Scikit-learn
- Machine Learning
- Digital Twin Simulation

## Project Status

This is an experimental research/development project and not a
production manufacturing control system.
